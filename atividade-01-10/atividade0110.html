🚨 Incidente StarLog-Zero

Briefing de Incidente Operacional & Caderno de Requisitos Técnicos

Data Estelar: Ano 2026

Local: Estação Espacial de Cargas StarLog-Zero

Janela Operacional: 80 Minutos

O sistema de suporte à vida e logística entrou em colapso após um pico de energia. Os relatórios de telemetria registraram quatro falhas críticas no código legado:

  1. Cargas com identificador vazio foram aceitas na esteira, corrompendo a base.
  2. Contêineres com limite de 3 unidades aceitaram 4 ou mais cargas por falta de validação segura.
  3. Cargas clonadas (mesmo código de rastreio) furaram o fluxo de triagem.
  4. O servidor travou sob 100% de CPU devido ao uso de laços imperativos lentos na geração de relatórios.

Missão do Squad: Reconstruir o motor de dados do zero, aplicando padrões de Engenharia.

⏳ FASES DA OPERAÇÃO:

  • 00 a 15 min: VSCode Fechado! Desenho da arquitetura no StarUML.
  • 15 a 60 min: Codificação em equipe das classes nos pacotes oficiais.
  • 60 a 75 min: Injeção do Chaos Monkey na MainResgate.java.
  • 75 a 80 min: Auditoria de compilação via terminal (javac).

📋 Caderno de Requisitos Técnicos (O Backlog)

PACOTE 1: br.com.starlog.model (Entidades de Domínio)

📦 Classe 1: Carga.java (Entidade com Identidade Única)

  • RN01 - Encapsulamento & Imutabilidade: Atributos privados: codigoRastreio (String), categoria (String), pesoKg (double) e valorSeguro (double). O atributo codigoRastreio deve ser final. Não crie método setCodigoRastreio().
  • RN02 - Barreira Defensiva Fail-Fast: No construtor, antes de qualquer atribuição, valide se codigoRastreio é nulo ou composto apenas por espaços (trim().isEmpty()). Se for inválido, lance: 
    throw new IllegalArgumentException("Codigo de rastreio da carga nao pode ser nulo ou vazio.");
    Valide também se pesoKg > 0. Caso contrário, lance IllegalArgumentException.
  • RN03 - Contrato de Hash (equals e hashCode): Sobrescreva ambos os métodos baseando-se estritamente no codigoRastreio. Nunca inclua pesoKg, categoria ou valorSeguro no hash para preservar a busca no HashSet.
  • RN04 - Representação Textual: Sobrescreva toString() retornando o padrão:
    Carga [rastreio=<codigoRastreio>, categoria=<categoria>, peso=<pesoKg>kg, seguro=R$ <valorSeguro>]

PACOTE 2: br.com.starlog.exception (Resiliência Operacional)

🛡️ Classe 2: CapacidadeExcedidaException.java (Checked Exception)

  • RN05 - Hierarquia Compulsória: A classe deve herdar diretamente de java.lang.Exception (Checked Exception). É proibido estender RuntimeException.
  • O construtor deve receber a mensagem de erro descritiva e encaminhá-la via super(mensagem);.

PACOTE 1 (Continuação): Agregadores e Motor Funcional

🚢 Classe 3: ModuloCarga.java (Contêiner Físico)

  • RN06 - Atributos e Inicialização: Atributos privados: idModulo (String), capacidadeMaxima (int) e List<Carga> cargas. Inicialize a lista no construtor (this.cargas = new ArrayList<>();).
  • RN07 - Trava Física de Capacidade (Fail-Fast): Método: public void carregarCarga(Carga carga) throws CapacidadeExcedidaException.
    Se this.cargas.size() >= this.capacidadeMaxima, aborte disparando: 
    throw new CapacidadeExcedidaException("Capacidade maxima de " + this.capacidadeMaxima + " atingida no modulo " + this.idModulo);
    Havendo vaga, adicione a carga à lista interna.
  • RN08 - Processamento Declarativo (Streams API — sem for ou if):
    • public double calcularSeguroTotal(): Soma do seguro de todas as cargas usando .stream().mapToDouble(Carga::getValorSeguro).sum().
    • public long contarPorCategoria(String categoria): Contagem de cargas da categoria com .stream().filter(...).count().
    • public double calcularSeguroPesadas(double pesoCorte): Soma do seguro apenas das cargas com peso superior ao corte, encadeando .filter(), .mapToDouble() e .sum().

🏛️ Classe 4: BaseLancamento.java (Gerenciador com Busca O(1))

  • RN09 - Indexação Associativa: Atributo privado: Map<String, ModuloCarga> modulos = new HashMap<>();.
  • cadastrarModulo(ModuloCarga modulo): Adiciona o módulo usando idModulo como chave (.put(...)).
  • buscarModulo(String idModulo): Retorna o módulo em O(1) via chave (.get(...)).

⚡ Fase 3: Protocolo Chaos Monkey (Minuto 60 a 75)

⚠️ Alerta de Injeção de Falhas: Os 4 testes de estresse abaixo devem ser executados a partir do método main da classe MainResgate.java para validar a resiliência do sistema sem modificar o código de modelo já entregue. 
// =========================================================================
// PROTOCOLO DE TESTES DE ESTRESSE (CHAOS MONKEY - 4 ATAQUES)
// =========================================================================
// Lembrete: Importe java.util.Set, java.util.HashSet e as classes dos pacotes model e exception!
// ATAQUE 1: Injeção de Carga com Dados Espúrios (Fail-Fast)
try {
    Carga fantasma = new Carga("    ", "CRIOGENICA", 10.0, 500.0);
    System.out.println("❌ FALHA: Aceitou codigo vazio!");
} catch (IllegalArgumentException e) {
    System.out.println("✅ SUCESSO ATAQUE 1 (Fail-Fast ativado): " + e.getMessage());
}

// ATAQUE 2: O Clone das Sombras (Teste de Integridade Hash)
Set<Carga> esteiraTriagem = new HashSet<>();
Carga c1 = new Carga("ORB-999", "ALIMENTOS", 10.0, 100.0);
Carga c1Clone = new Carga("ORB-999", "DADOS_ALTERADOS", 999.0, 8000.0); // Mesmo ID, memoria diferente!

esteiraTriagem.add(c1);
esteiraTriagem.add(c1Clone); // O Set DEVE recusar a duplicata!

if (esteiraTriagem.size() == 1) {
    System.out.println("✅ SUCESSO ATAQUE 2 (Hash imune a clones): Tamanho do Set = 1");
} else {
    System.out.println("❌ FALHA: O clone furou a dispersão e entrou no Set! Tamanho = " + esteiraTriagem.size());
}

// ATAQUE 3: O Teste de Ruptura de Limite (Checked Exception)
ModuloCarga moduloTeste = new ModuloCarga("MOD-TESTE", 2);
try {
    moduloTeste.carregarCarga(new Carga("C-01", "GERAL", 5.0, 50.0));
    moduloTeste.carregarCarga(new Carga("C-02", "GERAL", 5.0, 50.0));
    // A 3ª carga DEVE explodir o alarme!
    moduloTeste.carregarCarga(new Carga("C-03", "GERAL", 5.0, 50.0));
    System.out.println("❌ FALHA: Deixou ultrapassar a capacidade fisica!");
} catch (CapacidadeExcedidaException e) {
    System.out.println("✅ SUCESSO ATAQUE 3 (Trava de Limite operante): " + e.getMessage());
}

// ATAQUE 4: Processamento Analítico Funcional (Streams API)
// O moduloTeste tem 2 cargas de R$ 50.00 cada = R$ 100.00
double seguroCalculado = moduloTeste.calcularSeguroTotal();
System.out.println("✅ SUCESSO ATAQUE 4 (Streams Calculado): R$ " + seguroCalculado);
